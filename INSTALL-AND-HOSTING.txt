DRIVERSMART AI 8.1 — ANDROID INSTALLABLE WEB APP

This package preserves the Version 8.1 dashboard and adds the files required for a Progressive Web App (PWA):
- index.html: app
- manifest.webmanifest: install name, icon and standalone display settings
- service-worker.js: offline app-shell caching
- icons/: Android install icons

IMPORTANT: Chrome cannot install a PWA from a content:// local download address. The package must be published at an HTTPS website first. This ZIP does not publish itself and does not include hosting.

FREE HOSTING OPTION: GitHub Pages
1. On your phone or computer, sign in to GitHub and create a new PUBLIC repository named driversmart-ai.
2. Choose Add file > Upload files.
3. Upload the CONTENTS of this folder (index.html, manifest.webmanifest, service-worker.js, icons folder). Do not upload only the ZIP.
4. Commit the files to the main branch.
5. Open repository Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
7. Wait for GitHub Pages to publish. Your site URL will look like https://YOUR-GITHUB-USERNAME.github.io/driversmart-ai/ . The exact username is yours; do not use this example URL literally.
8. Open the published HTTPS URL in Chrome on Android. Wait for the page to finish loading.
9. Tap Chrome menu (three dots) > Install app. If Install app is not shown, choose Add to Home screen.
10. Confirm. DriverSmart AI will appear on your home screen.

DATA NOTE:
Ride data is stored locally in the browser on this device (localStorage and IndexedDB). It is not synchronized to GitHub or to another phone. Use the app's Backup/Restore section regularly and keep backup files somewhere safe. Clearing Chrome site data can erase local ride records.

LYFT/UBER NOTE:
Ride entries remain manual. This app does not sign in to or automatically import trips from Lyft or Uber.
